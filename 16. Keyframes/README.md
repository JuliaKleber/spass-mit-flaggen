# Ladezustände mit Keyframes

## Ziel

Ziel ist es verschiedene Ladezustände mit Hilfe von Keyframes darzustellen.

## Aufgabenstellung

Implementiere die folgenden Ladezustände

- Loading Spinner
- Pulsierendes Skeleton
- Schimmerndes Skeleton
- Bouncing Dots
