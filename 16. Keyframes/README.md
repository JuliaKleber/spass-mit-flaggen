# Ladezustände mit Keyframes

## Ziel

Ziel ist es verschiedene Ladezustände mit Hilfe von Keyframes darzustellen.

## Aufgabenstellung

Implementiere die folgenden Ladezustände

- Loading Spinner: Kontinuierliche Rotation
- Pulsierendes Skeleton: Ein sanfter Wechsel der Deckkraft
- Schimmerndes Skeleton: Ein vorbeiziehender Lichteffekt
- Bouncing Dots: Zeitversetzt hüpfende Punkte
