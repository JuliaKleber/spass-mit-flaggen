# Ladezustände mit Keyframes

## Lernziel

In dieser Aufgabe lernst du, verschiedene Ladezustände mithilfe von **CSS-Keyframe-Animationen** ansprechend zu visualisieren.

## Hintergrund

Eine gute User Experience (UX) erfordert kontinuierliches Feedback. Anstatt den Nutzer vor einer leeren Seite warten zu lassen, signalisieren Ladeanimationen, dass die Anwendung aktiv Daten verarbeitet. Dies reduziert die gefühlte Wartezeit und verhindert Unsicherheit beim Anwender.

## Aufgabenstellung

Implementiere die folgenden Ladezustände:

- **Loading Spinner:** Kontinuierliche Rotation
- **Pulsierendes Skeleton:** Ein sanfter Wechsel der Deckkraft
- **Schimmerndes Skeleton:** Ein vorbeiziehender Lichteffekt
- **Bouncing Dots:** Zeitversetzt hüpfende Punkte

Das HTML und das Basis-Styling für Spinner, Skeletons (die als Platzhalter für Flaggen dienen) und Dots sind bereits vorbereitet. Deine Aufgabe ist es, diese Elemente nun mithilfe von Keyframes zu animieren.
