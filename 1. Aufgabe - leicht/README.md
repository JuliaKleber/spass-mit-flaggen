# Spaß mit Flaggen

## Aufgabenstellung

Erstelle die folgenden Flaggen unter zu Hilfenahme von <b>Flexbox</b>

<ul>
  <li>Deutschland</li>
  <li>Irland</li>
  <li>Japan</li>
  <li>Benin</li>
</ul>

## Hinweise

<ul>
  <li>
    Die Flaggen sollten ein Seitenverhältnis von 3 : 2 aufweisen.
  </li>
  <li>Es sollten keine Libraries oder Frameworks genutzt werden.</li>
  <li>Es sollte css-Nesting genutzt werden. Link ?</li>
  <li>Es sollte ein externes Stylesheet genutzt werden. Link ?</li>
  <li>Hinweis auf html-Struktur mit title und meta viewport.</li>
</ul>

### Farben der Flaggen

<ul>
  <li>Deutschland: rgb(0, 0, 0), rgb(255, 0, 0), rgb(255, 204, 0)</li>
  <li>Irland: rgb(22, 155, 98), rgb(255, 255, 255), rgb(255, 136, 62)</li>
  <li>Japan: rgb(255, 255, 255), rgb(188, 0, 45)</li>
  <li>Benin: rgb(0, 136, 86), rgb(252, 209, 22), rgb(227, 28, 35)</li>
</ul>

### Benötigte css-Properties

<ul>
  <li>display, flex-direction, justify-content, align-items, gap, flex-wrap</li>
  <li>width, height</li>
  <li>background-color</li>
  <li>border-radius</li>
</ul>
