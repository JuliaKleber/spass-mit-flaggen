Allgemeine Hinweise

  • Die Flaggen sollten ein Seitenverhältnis von 3 : 2 aufweisen.
  • Es sollten keine Libraries oder Frameworks genutzt werden.
  • Es sollte css-Nesting genutzt werden. Link ?
  • Es sollte ein externes Stylesheet genutzt werden. Link ?
