# 🇬🇧 Fun with Flags

“Fun with Flags” is a collection of exercises focusing on CSS (Cascading Style Sheets) and SVG (Scalable Vector Graphics).

The repository contains a directory for each topic. Except for directory 13, each folder contains a `README.md` file with the instructions, an HTML file that should be used as is, and a rudimentary stylesheet (`styles.css`) that needs to be completed. In directory 13, however, the HTML file is the one to be edited, while the stylesheet remains unchanged.

The most important exercises cover the box model (exercise 1), Flexbox (exercise 4), and positioning (exercise 6). However, there are more elegant ways to create flags, for example, using gradients (exercise 9), the CSS property `clip-path` (exercise 10), or creating flags as SVGs (exercise 13). If you already have some knowledge of CSS, you can start directly with exercise 12.

And now: Have fun with flags! 😃 🙌 🏳️‍🌈

# 🇩🇪 Spaß mit Flaggen

Bei "Spaß mit Flaggen" handelt es sich um eine Aufgabensammlung zum Thema CSS (Cascading Style Sheets) und SVG (Scalable Vector Graphics).

Im Repo ist zu jedem Thema ein Verzeichnis zu finden. In allen Verzeichnissen, mit Ausnahme von Aufgabe 13, befindet sich jeweils eine `README.md` mit der Aufgabenstellung, eine HTML-Datei, die so verwendet werden kann und soll, wie sie ist, und ein rudimentäres Stylesheet (`styles.css`), das vervollständigt werden soll. Im Verzeichnis zu Aufgabe 13 soll hingegen die HTML-Datei vervollständigt werden. Das Stylesheet in dem Verzeichnis soll nicht verändert werden.

Die wichtigsten Übungen behandeln das Box-Model (Aufgabe 1), Flexbox (Aufgabe 4) und Position (Aufgabe 6). Allerdings gibt es elegantere Wege, Flaggen zu erstellen, zum Beispiel unter Verwendung von Gradienten (Aufgabe 9), der CSS-Eigenschaft `clip-path` (Aufgabe 10) oder als reine SVG-Grafiken (Aufgabe 13). Wer bereits CSS-Vorkenntnisse hat, kann direkt mit Aufgabe 12 einsteigen.

Und nun: Viel Spaß mit Flaggen! 😃 🙌 🏳️‍🌈
