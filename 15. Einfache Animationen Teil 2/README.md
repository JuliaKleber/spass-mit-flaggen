# Einfache Animationen Teil 2

## Ziel

Ziel ist es Flaggen zu animieren, wenn man über sie hovert. Dafür sollen die CSS-Eigenschaften transition und filter genutzt werden.

## Aufgabenstellung

Implementiere die folgenden Hover-Effekte

- 🇳🇱 Niederlande: Flagge wird in komplett in Graustufen angezeigt
- 🇮🇹 Italien: Die Graustufen werden auf 50% gesetzt
- 🇲🇺 Mauritius: Flagge wird zu 50% abgedunkelt
- 🇹🇭 Thailand: Flagge wird zu 50% aufgehellt
- 🇧🇯 Benin: Kontrast wird zu 50% heruntergesetzt
- 🇸🇪 Schweden: Konstrast wird zu 50% heraufgesetzt
- 🇯🇵 Japan: Die Farbsättigung wird um 50% heruntergesetzt
- 🇵🇼 Palau: Die Farbsättigung wird um 50% hochgesetzt
- 🇨🇭 Schweiz: Die Flagge ist zu 50% durchscheinend
- 🇨🇿 Tschechische Republik: Die Farben der Flagge werden um 180° auf dem Farbkreis verschoben
- 🇧🇸 Bahamas: Die Farben der Flagge werden um 90° auf dem Farbkreis verschoben
- 🇹🇹 Trinidad und Tobago: Flagge bekommt einen Drop-Shadow
- 🏴󠁧󠁢󠁳󠁣󠁴󠁿 Schottland: Flagge bekommt einen Box-Shadow
- 🇯🇲 Jamaika: Flagge bekommt einen Sepia-Filter
- 🇸🇨 Seychellen: Die Farben werden invertiert
- 🇲🇰 Nordmazedonien: Flagge wird verschwommen

## Anforderungen

- Es soll eine Transition-Time von 150ms genutzt werden, wenn der Mauszeiger auf die Flagge geht und eine Transition-Time von 450ms, wenn der Mauszeiger die Flagge verlässt.
- Die HTML-Datei soll nicht verändert werden. Nur das Stylesheet soll vervollständigt werden.
- Es sollen keine Libraries oder Frameworks genutzt werden.
