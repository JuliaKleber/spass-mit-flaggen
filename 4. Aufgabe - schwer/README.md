# Spaß mit Flaggen - Aufgabe 4

## Aufgabenstellung

Baue die folgenden Nationalflaggen mit reinem HTML und CSS:

- Tschechische Republik
- Bahamas
- Schottland
- Großbritanien

## Anforderungen

- Jede Flagge sollte ein Seitenverhältnis von 3 : 2 aufweisen.
- Es sollte konsequent Flexbox zur Erstellung der Flaggen genutzt werden.
- Es sollten keine Libraries oder Frameworks genutzt werden.
- Es sollte CSS-Nesting genutzt werden.
- Es sollte ein externes Stylesheet genutzt werden.

### Farben der Flaggen

Die folgenden Farben können für die Erstellung der Flaggen genutzt werden:

- Tschechische Republik: rgb(255, 255, 255), rgb(215, 20, 26), rgb
  (17,49,126)
- Bahamas: rgb(0, 169, 206), rgb(255, 199, 44), rgb(0,169, 206),
  rgb(0, 0, 0),
- Schottland: rgb(1, 33, 105), rgb(255, 255, 255)
- Großbritannien: rgb(255, 255, 255), rgb(1, 33, 105), rgb(200, 16, 46)

### Benötigte css-Properties

- position
- top, bottom, right, left
- z-index
- transformations: rotate, translate
- border
- Erstellung von Dreiecken: www.html-seminar.de
