# Spaß mit Flaggen - Aufgabe 12 (Verschiedenes)

## Aufgabenstellung

Baue die folgenden Nationalflaggen mit reinem HTML und CSS:

- 🇬🇧 Großbritanien
- 🇬🇱 Grönland
- 🇯🇲 Jamaika

## Anforderungen

- Für die Maße der Flaggen und die Farben sollten CSS-Variablen genutzt werden.
- Es sollten keine Libraries oder Frameworks genutzt werden.

## Hinweise

- 🇬🇱 Grönland 3:2

## Farben der Flaggen

Die folgenden Farben können für die Erstellung der Flaggen genutzt werden:

- 🇬🇱 Grönland: rgb(208, 12, 51), rgb(255, 255, 255)
- Großbritannien: rgb(255, 255, 255), rgb(1, 33, 105), rgb(200, 16, 46)
- Jamaika: rgb(0, 155, 58), rgb(254, 209, 0), rgb(0, 0, 0);
