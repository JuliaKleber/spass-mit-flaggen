Spaß mit Flaggen

Bei "Spaß mit Flaggen" handelt sich um eine Aufgabensammlung zum Thema CSS (Cascading Style Sheets). Im Repo ist zu jedem Thema ein Verzeichnis zu finden. In den Verzeichnissen befindet sich jeweils eine README.md mit der Aufgabenstellung, eine html-Datei, die so verwendet werden kann wie sie ist und ein rudimentäres Stylesheet, das vervollständigt werden soll. Und nun viel Spas mit Flaggen! 😃 🙌 🏳️‍🌈

  • Grid
  • Position
  • Gradient
  • Box-Shadow & ::before
