Spaß mit Flaggen

Bei "Spaß mit Flaggen" handelt sich um eine Aufgabensammlung zum Thema CSS (Cascading Style Sheets). Im Repo ist zu jedem Thema ein Verzeichnis zu finden. In den Verzeichnissen befindet sich jeweils eine README.md mit der Aufgabenstellung, eine html-Datei, die so verwendet werden kann wie sie ist und ein rudimentäres Stylesheet (styles.css), das vervollständigt werden soll.

Die wichtigsten Übungen sind unter "Box-Model: padding, margin, border", "Flexbox" und "Position" zu finden. Allerdings gibt es elegantere Wege Flaggen zu erstellen, zum Beispiel unter Verwendung von Gradienten.
